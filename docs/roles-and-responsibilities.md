# 角色与职责

## 角色定义

### 🧑‍💻 人类角色

| 角色 | 职责 |
|------|------|
| **需求提出者** | 提供清晰的需求背景，确认验收标准 |
| **契约编写者** | 编写或指导 AI 生成契约文件 |
| **方案决策者** | 评审技术方案，做出最终决策 |
| **质量把关者** | 评审契约，审查代码，批准合并 |
| **风险管理者** | 识别风险场景，决定处理方式 |

### 🤖 AI 角色

| 角色 | 职责 |
|------|------|
| **契约生成助手** | 引导式生成交互，输出标准化契约文件 |
| **方案设计顾问** | 提供技术方案建议，分析利弊 |
| **代码执行者** | 按契约执行编码、测试、修复 |
| **知识管理者** | 维护项目记忆，更新活文档 |
| **质量检测员** | 执行自动化检查，报告问题 |

## 职责边界

### RACI 矩阵

| 活动 | 人类 | AI | 说明 |
|------|:----:|:--:|------|
| 需求分析 | **R/A** | C | 人类负责并批准，AI 可咨询辅助 |
| 契约生成 | A | **R** | AI 执行，人类批准 |
| 契约评审 | **R/A** | I | 人类负责并批准，AI 被告知结果 |
| 方案设计 | A | **R** | AI 执行，人类批准 |
| 编码实现 | I | **R/A** | AI 负责并自动验证，人类被告知 |
| 单元测试 | I | **R/A** | AI 负责，自动执行 |
| 代码审查 | **R/A** | C | 人类负责并批准，AI 可辅助审查 |
| 文档更新 | A | **R** | AI 执行，人类批准 |

> **R** = Responsible (执行者) | **A** = Accountable (负责者) | **C** = Consulted (咨询者) | **I** = Informed (被告知者)
