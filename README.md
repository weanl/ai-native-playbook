# AI Native Playbook

> **让 AI 成为你的编程队友，而非仅仅是工具。**

## 🎯 项目简介

`ai-native-playbook` 是一套面向 AI 时代的研发实战手册。它重新定义了人机协作的边界，通过**契约驱动**的流程设计，让 AI 能够像团队成员一样参与编码、测试和文档维护，同时确保人类保留核心决策权。

## ✨ 核心特性

| 特性 | 说明 |
|------|------|
| **契约驱动** | 通过 Proposal / Design / Tasks 三份契约文件，统一人与 AI 的信息源，消除沟通歧义 |
| **多层门禁** | 编码前的契约评审 + 编码后的代码审查，双重保障质量底线 |
| **项目记忆** | 参考 OpenSpec 归档机制让 AI 拥有项目全局视野，告别"每一次都从零开始" |
| **分级流程** | 依据任务复杂度自动匹配 Level 1/2/3 流程，避免"杀鸡用牛刀" |
