# Interaction Checklist

Before finishing a prototype, check:

## Navigation

- Can the user move between major screens?
- Is the current section visually active?
- Does the mobile layout still expose navigation?

## Buttons

- Does every primary button do something visible?
- Do destructive buttons ask for confirmation?
- Do save buttons show success feedback?
- Do disabled buttons look disabled?

## Forms

- Are required fields labeled?
- Does validation show useful messages?
- Does successful submission update the UI?
- Are errors visible near the relevant field?

## Modals and drawers

- Can they be opened?
- Can they be closed?
- Is there a visible overlay or boundary?
- Does the primary action change state?

## Tables and lists

- Does search or filtering visibly affect rows?
- Can row click open detail when relevant?
- Is there an empty state when no results match?

## Feedback

- Is there a toast or alert for important actions?
- Is loading state represented?
- Is error state represented?

## Responsive

- Does the prototype remain usable around 390px width?
- Does content wrap rather than overflow?
- Are tap targets large enough?
