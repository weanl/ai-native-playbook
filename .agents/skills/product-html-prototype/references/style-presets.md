# Style Presets

Use these presets when the user gives no specific style.

## Modern B2B SaaS

Use for admin panels, dashboards, CRM, analytics, AI tools, workflow tools, internal tools.

Characteristics:
- left sidebar or top navigation
- white cards on light neutral background
- subtle borders
- rounded 12px to 16px corners
- restrained shadows
- slate/gray text hierarchy
- blue, indigo, or violet accent
- medium information density
- clear tables and forms

## Developer Tool

Use for API platforms, DevOps tools, AI agent tools, logs, workflow automation.

Characteristics:
- precise layout
- optional code/log panels
- monospace only for technical snippets
- command palette or quick action patterns
- status badges
- API key or environment panels
- calm dark or light mode

## Executive Dashboard

Use for reporting, KPI monitoring, business reviews, financial or operational dashboards.

Characteristics:
- KPI cards
- trend panels
- risk alerts
- summary-first hierarchy
- grouped metrics
- clear filters
- high information density with strong grouping

## Consumer App

Use for mobile-first or consumer product flows.

Characteristics:
- larger touch targets
- bottom navigation when mobile-first
- stronger visual rhythm
- friendly copy
- onboarding and success moments
- less dense than B2B

## AI Product

Use for AI assistant, AI workflow, prompt, agent, model, or automation products.

Characteristics:
- input composer
- conversation or task history
- run status
- generated output preview
- review and approve flows
- clear distinction between human input and AI output
- trust and safety messaging where relevant

## Marketing Landing Page

Use only when the user asks for landing pages.

Characteristics:
- hero section
- product value proposition
- feature cards
- social proof placeholders
- pricing or CTA
- FAQ
- polished but not overdecorated
