关键状态样例

状态层次页面含义用户提示
emptyUI 通用状态暂无候选模型或筛选无结果提示下一步创建、导入或清除筛选
loadingUI 通用状态组件加载中展示骨架屏，关键动作暂不可用
running任务状态实验或训练正在执行允许查看详情，禁止晋级动作
failed任务状态任务失败展示 run id、job id、错误摘要和追溯入口
partial_failed批量状态部分组合失败保留成功结果，同时展示失败组合
candidate模型生命周期候选模型等待证据评审展示 evidence panel
active模型生命周期当前生效模型允许对比和回滚调查
archived生命周期状态历史对象仅用于审计只读展示，不参与新训练
