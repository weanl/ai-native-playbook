Overview

演示对象
KPI Checkout API latency 从数据实验到策略模拟，再承接为 train job、model version 与 promotion event。
从数据版本开始实验
优先闭环 A：数据实验与算法选择 current priority
优先闭环 B：每日新增数据后的离线策略模拟 dry-run / backtest
策略模拟推荐 winning config
后续承接主流程：落成模型版本、晋级事件与 active pointer manual promotion
停止与复核 no active change
恢复与审计 rollback audit
边界说明：M2 可实现离线策略模拟和效果指标报告；真实无人值守 auto-active、在线 serving、生产流量切换、多租户权限仍不属于当前主流程。
