# M2-024 用户旅程

## 目标

本原型围绕一个核心闭环：

```text
选择或上传数据 → 数据预览 → 实验配置 → 创建/启动任务 → 查看结果
```

既覆盖 M1.6 的单算法/多算法批量实验，也承载 M2 滚动实验能力。滚动策略作为实验配置、任务管理、结果查看中的关键要素。

本文只定义产品旅程，不定义后端 schema，不实现生产模型生命周期。

## 角色

### 平台评估者

关注点：

- 是否能从导入数据跑完端到端算法实验。
- 批量实验排行榜和算法×文件矩阵是否一目了然。
- M2 滚动策略配置是否可理解。

### 算法工程师

关注点：

- 每个算法/参数组合的指标（F1 / PA-F1 / TP / FP / FN）。
- DatasetBundle 多文件场景下哪个算法在哪个文件翻车。
- 滚动训练窗口和 active 策略的影响。
- 跨日算法排行与稳定性。

## 演示主线

### 1. 数据接入

演示目标：

- 上传 CSV / .out / npy/npz / zip 或选择内置数据集。
- DatasetBundle 多文件自动形成 bundle，展示文件回显和 schema ok 状态。
- 多天数据时展示日分区列表与质量状态。
- 数据来源切换时预览与实验上下文同步刷新。

### 2. 数据预览

演示目标：

- 展示行数、列数、指标列、真实异常点数和异常比例。
- 指标曲线 + Label 异常段叠加。
- 字段质量（角色、dtype、缺失率）和数据样例。
- 多天数据时：日分区质量状态、无效分区排除原因。

### 3. 实验配置

演示目标：

- 单算法实验 / 多算法实验 / 滚动实验切换。
- 算法参数表单（默认值、类型、含义），不再手写 JSON。
- 批量算法范围勾选，展示任务矩阵（算法数 × 文件数）。
- **滚动策略配置（滚动实验时必填）**：
  - 滚动模式：累积 / 滑动窗口。
  - 训练窗口长度（默认 1 天）。
  - active 策略：latest model auto-active。
  - 质量门禁：label coverage 门槛。
- 创建实验任务：仅创建 / 创建并启动。

### 4. 任务管理

演示目标：

- 实验任务列表：任务标识、数据标识、算法标识、类型（单算法/多算法/滚动）、状态、子任务数。
- 子任务抽屉：algorithm × file 矩阵的 cell 级状态。
- **滚动任务特有信息**：
  - 当前 cutoff day 进度。
  - active model 状态。
  - blocked 时间段。
  - partial_failed 算法状态。
- 启动/重跑按钮。

### 5. 结果查看

演示目标：

- 单算法结果：TP / FP / FN / TN 数量、指标含义表、结果曲线 iframe。
- 多算法批量结果：总排行榜、算法×文件矩阵、文件钻取、Cell 明细。
- **滚动实验结果**：
  - Active Timeline（每天使用的 active 模型）。
  - Prediction Ledger 预览。
  - 算法跨日排行（mean PA-F1、稳定性、success_rate）。
  - 排除项汇总（blocked 时间段、failed 算法、无效分区原因）。
- failed cell 不阻断其他结果展示。

## 异常旅程

### 数据源切换

```text
切换数据源 → 预览与实验上下文同步刷新 → toast 提示
```

### 算法/文件组合失败

```text
某 cell 失败 → 该行标记 FAILED → 其余 cell 仍 COMPLETED → 结果页 failed cell 可钻取
```

### DatasetBundle 多文件场景

```text
上传 bundle → schema 一致性校验 → 不一致时 fail-fast + 展示冲突
```

### 滚动实验 blocked 时间段

```text
某 cutoff day 无有效训练数据 → 该时间段标记 blocked → 不参与 auto-active 统计 → 结果页展示 blocked 原因
```

### 滚动实验 partial_failed

```text
某算法在某 cutoff day 失败 → 标记 partial_failed → 其余算法继续 → 结果页展示 failed 算法与原因
```
