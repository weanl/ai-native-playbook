# NextAIOpsSystem 概览

> 一页纸说明 NextAIOpsAlgoApp 在系统中的位置与边界。

## 系统定位

NextAIOpsSystem 是面向企业 IT 全生命周期（规划 / 建设 / 维护 / 优化 / 运营）的智能运维系统。

## 主要子系统与算法平台的关系

| 子系统 | 一句话职责 | 与算法平台的关系 |
|---|---|---|
| **NextAIOpsAlgoApp**（本仓库） | 算法平台 / 智能大脑 | 自身 |
| 运维智能体 | 自然语言驱动的运维操作执行体（参考 NetClaw 范式） | 调用算法平台导出的模型 / 能力 |
| 监控采集 | 指标 / 日志 / 事件的统一接入 | 为算法平台提供训练 / 推理数据 |
| 可视化门户 | 全系统统一的运营视图 | 展示算法平台的实验与效果 |
| 知识库 | 故障 / 处置 / 配置等运维知识沉淀 | 为算法 / 智能体提供上下文 |

> 上述子系统除算法平台外，本阶段仅给出名称 + 职责，不做具体设计。

## 解耦原则

- 子系统间松耦合，可独立演进与部署
- 跨子系统通信走显式契约（REST / 事件），M0 阶段无外部接口
- 算法平台对其他子系统**只暴露交付物**（模型文件 + 实验配置），不暴露内部存储与流程

## 算法平台在系统中的角色

- **输入侧**：从监控采集 / 知识库获取训练数据（M0 以离线 CSV 替代）
- **输出侧**：向运维智能体 / 可视化门户交付模型与实验报告（M0 以本地导出文件替代）
- **演进独立性**：算法平台可独立迭代算法生态，不受业务子系统节奏制约
