# 黄金数据集说明

## 文件信息

- **文件名**：`metrics.csv`
- **格式**：CSV（逗号分隔）
- **行数**：1000 行数据 + 1 行 header = 1001 行
- **异常比例**：4%（40 个异常点）

## 列定义

| 列名 | 类型 | 角色 | 说明 |
|------|------|------|------|
| `timestamp` | int | TIMESTAMP | 时间索引（0~999） |
| `value` | float | METRIC | 指标值（正常值约 100±5，异常值偏离 50-100） |
| `is_anomaly` | int (0/1) | LABEL | 异常标签（1=异常，0=正常） |

## 异常点分布

异常点随机分布于时间序列中，共 40 个，位置示例：
- 索引：6, 25, 27, 30, 32, 89, 95, 104, 114, 142, ...
- 异常值偏离基准值约 50-100（约 3-5 sigma）

## 数据特征

- **基准值**：100.0
- **正常波动**：±5（1 sigma）
- **异常偏离**：±50 ~ ±100（10-20 sigma）
- **趋势**：轻微线性趋势（每 50 步增加 0.1）
- **随机种子**：42（可复现）

## 设计意图

本数据集设计用于验证异常检测算法的基本功能：

1. **非退化验证**：异常点明显偏离，应能被 3-Sigma 等简单算法检测到（F1 > 0）
2. **格式对标**：符合 Yahoo S5 A1 基准数据集格式（单指标 + 时间戳 + 标签）
3. **简洁可控**：单指标、无实体、无窗口标签，聚焦 M0 最小闭环

## 来源对标

参考 Yahoo Webscope S5（A1Benchmark_real_1.csv）格式：
- 列名：`timestamp`, `value`, `is_anomaly`
- 异常标记：0/1 整数

## 使用方式

```bash
# 冒烟测试
make smoke ALG=three_sigma

# CLI 运行
python -m nextaiops_algo run --data tests/smoke/golden_data/metrics.csv --algo three_sigma
```
